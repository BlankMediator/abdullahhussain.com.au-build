# abdullahhussain.com.au

Public deploy repository for `abdullahhussain.com.au`.

This repository contains only the final static website build.

## Project releases and integrity

The Syncex project lives at `projects/syncex.html`. Every listed public project has a release or pinned source snapshot in `downloads/manifest.json`, with actual-file SHA-256 hashes, byte sizes and URLs. `downloads/index.html` provides static hashes and local browser verification; no selected files are uploaded.

For each new release, download the final asset, compute SHA-256 from its bytes, and update the manifest, its `.sha256` sidecar, `SHA256SUMS.txt`, and the matching HTML hash and verifier option together. Source archives must use full commit SHAs, never moving branch URLs. Preserve old version entries if old downloads remain available. A new project needs a matching entry here before its download link is published.

Checksums establish integrity against a trusted value, not signing-key identity. The source snapshot entries are the exact archived commits shown, not fingerprints of a running website. Do not add private repository source or local application data to this public build.
