What’s in 2.3.0

The first Syncex release brings the existing Codex Profile Sync utility under its new name. It retains the working live relay, continuous journals and checkpoints, conflict tools and recovery. The ZIP includes the Python source, documentation, tests, file checksums and archive verifier.

The release owner has confirmed live operation and continuous backup on the configured two-account installation. All 85 public tests passed, and rebuilding the sanitized source reproduced the exact release ZIP.

Get started

  1. Verify and extract the ZIP into a folder both Windows users can access.
  2. Install Python with Tkinter, then open Start Syncex.cmd.
  3. Use Automatic setup or Manual setup, scan and select your tasks.
  4. Open Live mode, finish replies and quit both apps once when prompted. Syncex starts the relay and opens the owner followed by the second window.
  5. Keep the live panel open. For a durable copy in the receiving profile, finish the reply, close that app and wait for Saved in both.

Upgrading from Codex Profile Sync: keep your configuration and shared backup folder. The old launcher filename remains available. Restart Live mode after restarting Windows; Syncex does not install a background Windows service.

This independent utility supports the desktop format verified with app version 26.908.70816. The live relay checks its supported protocol hash and refuses unknown builds. Each profile keeps its own sign-in.
