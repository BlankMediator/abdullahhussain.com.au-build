Verify from a terminal

PowerShell on Windows:

Get-FileHash .\your-downloaded-file.zip -Algorithm SHA256

Compare all 64 hexadecimal characters with the value for that exact file above. On Linux, download the matching sidecar and run sha256sum -c filename.zip.sha256. On macOS use shasum -a 256 -c filename.zip.sha256.

SHA-256 verifies byte integrity against a trusted expected value. These checksums are not digital signatures from a signing key. If a file differs, do not use it; download the exact listed version again. A source archive hash applies to that archive, not to a built executable or the live website.
